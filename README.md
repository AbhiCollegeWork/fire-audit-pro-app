# Fire Audit Pro for Android

Downloads for the Fire Audit Pro app by Siya Habitats. This repository holds the app's release files only.

## Install

For auditors and firms. Takes about two minutes.

### 1. Download

Open this link on the phone or tablet:

https://github.com/AbhiCollegeWork/fire-audit-pro-app/releases/latest/download/FireAuditPro.apk

The file is about 5 MB and is called `FireAuditPro.apk`.

### 2. Install

1. Tap the downloaded file (in the browser's downloads or the Files app).
2. Android asks to allow installs from this source (Chrome or Files). Tap **Settings**, switch on
   **Allow from this source**, then go back.
3. Tap **Install**. If Play Protect shows a warning about an app it does not know, tap
   **More details**, then **Install anyway**. The app is signed by Siya Habitats.
4. Tap **Open**.

### 3. Sign in

Use the email and the temporary password Siya Habitats sent you. The first sign-in needs internet.
After that the app works with no signal and sends everything to the cloud by itself when the
signal comes back.

## Good to know

- **Updates arrive by themselves.** Nothing needs downloading again: the app fetches new versions
  in the background and switches to them the next time it opens.
- **Screenshots are switched off** inside the app, to keep audit data private. Share a report with
  the Download button: Word or PDF opens Android's share sheet (WhatsApp, email, Drive).
- **Photos** are taken from the Add photo button on each checkpoint. Allow camera access the first
  time.
- **Finalising** an audit waits until everything in it has reached the cloud, so nothing is lost if
  the phone is.
- **Demo accounts** run for 30 days. Everything recorded stays with you when you continue.
